#### လက်ရှိစာရင်းကောက်ယူမှု

<hr>
ဤမီနူးသည် စာရင်းကောက်ယူမှုပြုလုပ်ရန်အတွက် အဓိကမီနူးဖြစ်သည်။ ၎င်းကို စနစ်မှ ပျောက်ဆုံးသွားသည်ဟု ယူဆသော စာကြည့်တိုက်စုဆောင်းမှုများ၏ အခြေအနေကို ပြန်လည်ရယူရန် အသုံးပြုသည်။ ဤမီနူးတွင်၊ item id (ဘားကုဒ်နံပါတ်) သည် ပျောက်ဆုံးသွားသည်ဟု ယူဆသော item များ၏ အခြေအနေကို ရှိပြီးသား (ရှိပြီးသား) သို့ ပြောင်းလဲရန် အဓိက item reference ဖြစ်သည်။ Item Code အကွက်တွင် ဘားကုဒ်နံပါတ်ကို ရိုက်ထည့်ခြင်းဖြင့် ၎င်းကို လုပ်ဆောင်ပါ။ Initialize လုပ်ငန်းစဉ်ပြီးဆုံးသွားသောအခါ ဤမီနူးသည် အလုပ်လုပ်ပါလိမ့်မည်။
