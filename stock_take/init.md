#### Initialize

<hr>
Initialize မီနူးကို စတော့ရှယ်ယာများ စတင်စုဆောင်းရန်အတွက် အသုံးပြုသည်။ ဤမီနူးတွင် အောက်ပါ မီနူးခွဲများ ရှိပါသည်။
- StockTake အမည်-လုပ်ဆောင်ခဲ့သော စတော့ရှယ်ယာများ စုဆောင်းခြင်း လုပ်ဆောင်ချက်များ၏ အမည်။ သင်နှစ်သက်ရာ အမည်ကို စိတ်ကြိုက်ပြင်ဆင်ပါ။ ဤအကွက်ကို ဖြည့်ရပါမည်။

- GMD:- (မော်ဂျူးလမ်းညွှန် Master File -> GMD (အောက်ရှိ Authority Files) ကိုကြည့်ပါ။)

- Collection အမျိုးအစား- (မော်ဂျူးလမ်းညွှန် Master File -> Collection အမျိုးအစား (Lookup Files) အောက်တွင် ကြည့်ပါ။)

- တည်နေရာ- (မော်ဂျူးလမ်းညွှန် Master File -> တည်နေရာ (အောက်ရှိ Authority Files) ကိုကြည့်ပါ။)

- Shelf တည်နေရာ- Bibliography မော်ဂျူးရှိ အချက်အလက်ပစ္စည်းကို ရည်ညွှန်းသည်။

- Classification: Bibliography မော်ဂျူးရှိ classification အကွက်ကို ရည်ညွှန်းသည်။ classification အပိုင်းအခြားကို သတ်မှတ်ရန်အတွက် wildcard (*) ကို အသုံးပြုပါ။ ဥပမာအားဖြင့်၊ 100 မှ 300 အထိ အပိုင်းအခြားရှိသော classification များကို စတော့ရှယ်ယာများ စုဆောင်းလိုပါက 1\* မှ 3\* ကို ရိုက်ထည့်ပါ။ ကျွန်ုပ်တို့ ကုန်ပစ္စည်းစာရင်းကောက်ယူခြင်း အမျိုးအစားခွဲခြားမှု အတိုင်းအတာသည် ၁၀၀ တွင်ရှိပါက 1\* * ကို ရိုက်ထည့်ပါ။

Initialization ပြီးဆုံးပြီးနောက် Current StockTake မီနူးနှင့် StockTake Report တို့သည် ကုန်ပစ္စည်းစာရင်းကောက်ယူခြင်း လုပ်ဆောင်ချက်များအတွက် မီနူးများအဖြစ် ဆောင်ရွက်မည်ဖြစ်ပြီး StockTake Finish မီနူး၊ Current Lost Items၊ StockTake Log နှင့် Resynchronise တို့နှင့်အတူ ကုန်ပစ္စည်းစာရင်းကောက်ယူခြင်းကို လုပ်ဆောင်ရန် အသုံးပြုမည့် navigation မီနူးနှင့်အတူ တွဲဖက်အသုံးပြုပါမည်။
