### စာကြည့်တိုက်မှူးနှင့် စနစ်အသုံးပြုသူများ ပရိုဖိုင်များ

------

၎င်းတို့၏ ခွင့်ပြုချက်များအရ မည်သည့်အသုံးပြုသူများသည် စနစ်ကို ဝင်ရောက်နိုင်သည်ကို ဆုံးဖြတ်ရန် အထောက်အကူပြုပစ္စည်းတစ်ခု။ ဤအသုံးပြုသူများသည် အသုံးပြုသူအမည်နှင့် စကားဝှက်ဖြင့် စာကြည့်တိုက်စီမံခန့်ခွဲမှုသို့ ဝင်ရောက်နိုင်မည်ဖြစ်သည်။ ထို့အပြင်၊ ဝင်ရောက်ထားသော ဝန်ထမ်းများသည် ၎င်းတို့၏ဒေတာကို တည်းဖြတ်နိုင်သည်၊ စကားဝှက်များ သတ်မှတ်နိုင်သည်၊ နှင့် နှစ်ဆင့်အထောက်အထားစိစစ်ခြင်းကို သတ်မှတ်နိုင်သည်။

#### Home -> အသုံးပြုသူပရိုဖိုင်ကို ပြောင်းလဲပါ

ဤမီနူးတွင် အသုံးပြုသူ တည်းဖြတ်ရန် ရွေးချယ်စရာများ ပါဝင်သည်-

* *ဝင်ရောက်သူအမည်* (အသုံးပြုသူအား ခွဲဝေပေးထားသော ဝင်ရောက်သူအမည်) - အသုံးပြုသူမှ ပြောင်းလဲ၍မရပါ။

* *အမည်ရင်း* (အသုံးပြုသူ၏ အမည်ရင်း)

* *အသုံးပြုသူအမျိုးအစား* (လုံခြုံရေးအဖွဲ့)

* *နောက်ဆုံးဝင်ရောက်သူ* (အသုံးပြုသူ နောက်ဆုံးဝင်ရောက်ချိန်)

* *နောက်ဆုံးအပ်ဒိတ်* (မှတ်တမ်းကို နောက်ဆုံးအပ်ဒိတ်လုပ်ချိန်)

* *အီးမေးလ်*

* *လူမှုမီဒီယာ*

* *အသုံးပြုသူဓာတ်ပုံ*

* *စကားဝှက်ဟောင်း ; စကားဝှက်အသစ် ; အတည်ပြုချက်*

* *နှစ်ဆင့်အထောက်အထားစိစစ်ခြင်းကို ဖွင့်ပါ*

မျက်နှာပြင်မှ မထွက်မီ မှတ်တမ်းကို **အပ်ဒိတ်လုပ်ပါ** ပြုလုပ်ရန် သေချာပါစေ။

------

#### စနစ် -> စာကြည့်တိုက်မှူးနှင့် စနစ်အသုံးပြုသူများ

ဤမီနူးအကြောင်းအရာကို super-user သာ ဝင်ရောက်နိုင်ပြီး ရွေးချယ်စရာများ ပါဝင်သည်-

- **အသုံးပြုသူအသစ်ထည့်ပါ** (အသုံးပြုသူများထည့်သွင်းခြင်း)၊
- **အသုံးပြုသူစာရင်း** (အသုံးပြုသူများစာရင်း)၊
- **ရှာဖွေပါ** (အသုံးပြုသူကို ရှာဖွေပါ)၊
- **တည်းဖြတ်ပါ** နှင့် **ဖျက်ပါ** အသုံးပြုသူ။

အသုံးပြုသူစာရင်းတွင် အသုံးပြုသူတစ်ဦးချင်းစီအတွက် အောက်ပါအချက်အလက်များကို ပြသထားသည်-

* *အမည်ရင်း* (အသုံးပြုသူ၏အမည်ရင်း)

* *လော့ဂ်အင်အသုံးပြုသူအမည်* (အသုံးပြုသူအား ခွဲဝေပေးထားသော လော့ဂ်အင်အမည်)

* *အသုံးပြုသူအမျိုးအစား* (လုံခြုံရေးအဖွဲ့)

* *နောက်ဆုံးဝင်ရောက်ခြင်း* (အသုံးပြုသူ နောက်ဆုံးဝင်ရောက်ချိန်)

* *နောက်ဆုံးအပ်ဒိတ်* (မှတ်တမ်းကို နောက်ဆုံးအပ်ဒိတ်လုပ်ချိန်)

ကော်လံ၏ထိပ်ရှိ ကွက်လပ်အမည်ကို နှိပ်ခြင်းဖြင့် စာရင်းကို ဤကွက်လပ်များထဲမှ တစ်ခုခုအလိုက် စီနိုင်သည်။ ဥပမာ- အသုံးပြုသူအမျိုးအစားအလိုက် စီရန် "အသုံးပြုသူအမျိုးအစား" ကို နှိပ်ပါ။

သော့ချက်စာလုံးများနှင့် ကိုက်ညီသော အသုံးပြုသူများအတွက် အသုံးပြုသူစာရင်းကို ရှာဖွေပေးမည့် ရှာဖွေရေးလုပ်ဆောင်ချက်တစ်ခု ရှိပါသည်။

ဤလုပ်ဆောင်ချက်ကို အရာများကို တည်းဖြတ်ရန်နှင့် ဖျက်ရန်အတွက်လည်း အသုံးပြုနိုင်ပါသည်။

အရာတစ်ခုကို တည်းဖြတ်ရန်၊ ခေါင်းစဉ်ကို နှစ်ချက်နှိပ်ပါ သို့မဟုတ် ခဲတံ (တည်းဖြတ်ရန်) အိုင်ကွန်ကို တစ်ချက်နှိပ်ပါ။

အသုံးပြုသူအချက်အလက်အတွင်း၊ အသုံးပြုသူသည် ၎င်းတို့၏ အင်တာနက်အထောက်အထားများ၊ ဥပမာ Facebook ပရိုဖိုင်၊ ဘလော့ဂ် သို့မဟုတ် ဝဘ်ဆိုက်များ စသည်တို့ကိုလည်း ထည့်သွင်းနိုင်သည်။

အသုံးပြုသူအသစ်ထည့်ရန်၊ **အသုံးပြုသူအသစ်ထည့်ရန်** ကို နှိပ်ပြီးနောက် Login အသုံးပြုသူအမည်၊ အမည်ရင်း၊ အသုံးပြုသူအမျိုးအစား (၎င်းတို့ပါဝင်မည့်) နှင့် စကားဝှက်တို့ကို ဖြည့်စွက်ပါ။ ၎င်းတို့သည် မဖြစ်မနေလိုအပ်ပါသည်။

ရွေးချယ်နိုင်သည်မှာ၊ အီးမေးလ်လိပ်စာ၊ Facebook၊ ဘလော့ဂ်လိပ်စာစသည့် လူမှုမီဒီယာအကောင့်အမျိုးမျိုးအကြောင်း အချက်အလက်များကို ထည့်သွင်းနိုင်သည်။

ရရှိနိုင်ပါက built-in ကင်မရာလုပ်ဆောင်ချက်ကို အသုံးပြု၍ အသုံးပြုသူဓာတ်ပုံကို အပ်လုဒ်လုပ်နိုင်သည် သို့မဟုတ် ရိုက်ကူးနိုင်သည်။

အမှန်ခြစ်ကွက်များသည် အဖွဲ့(များ) ထံသို့ ရွေးချယ်နိုင်သော ခွဲဝေမှုကို ခွင့်ပြုသည်- Admin၊ Circulation၊ Librarians၊ Visitors။

မျက်နှာပြင်မှ မထွက်မီ မှတ်တမ်းကို **သိမ်းဆည်း** ရန် သေချာပါစေ။
