### စတိုင်ဖွဲ့စည်းပုံ

------

ဤပုံစံကို အသုံးပြု၍ OPAC interface နှင့် Admin module interface style နှစ်မျိုးလုံးကို ရွေးချယ်နိုင်ပါသည်။

ရရှိနိုင်သော *Public template* များထဲမှ တစ်ခုကို ရွေးချယ်ပြီး **Activate** ခလုတ်ကို နှိပ်ခြင်းဖြင့် OPAC အသွင်အပြင်ကို သတ်မှတ်ပါသည်။ theme ကို အသက်သွင်းပြီးသည်နှင့်၊ သီးခြား theme အလိုက် ကွဲပြားမည့် အသွင်အပြင် setting အမျိုးမျိုးကို ပြောင်းလဲရန် **Customise** ခလုတ်ကို နှိပ်နိုင်ပါသည်။ စိတ်ကြိုက်ပြောင်းလဲမှုများ ပြုလုပ်ပြီးသည်နှင့်၊ *Theme configuration* pop-up မှ မထွက်ခွာမီ **Save settings** ခလုတ်ကို နှိပ်ရန် အရေးကြီးပါသည်။
