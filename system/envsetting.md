### စနစ်ပတ်ဝန်းကျင်ဆက်တင်

------

ဤမီနူးအရာသည် စနစ်ပတ်ဝန်းကျင်မုဒ်၏ သတ်မှတ်မှုကို ခွင့်ပြုသည်။

* **စနစ်ပတ်ဝန်းကျင်မုဒ်** [ထုတ်လုပ်မှု/ဖွံ့ဖြိုးတိုးတက်မှု] (ပုံသေ = ထုတ်လုပ်မှု)။ *ဖွံ့ဖြိုးတိုးတက်မှုကို ရွေးချယ်ခြင်းသည် အမှားအယွင်းများဖြစ်ပေါ်ပါက debug message အသေးစိတ်ကို ပြသနိုင်စေပြီး ပြဿနာရှာဖွေဖြေရှင်းသည့်အခါ ဤမုဒ်ကို အမြဲဖွင့်ထားသင့်သည်။*
* **အချို့သော IP အတွက်ပတ်ဝန်းကျင်လား။** [ဖွင့်/ပိတ်] (ပုံသေ = ပိတ်)။ *ဖွင့်ထားပါက၊ debug message များကို မည်သည့် client များက မြင်ရမည်ကို ထိန်းချုပ်ခွင့်ပြုသည်။*
* **IP အပိုင်းအခြား ...** .*အထက်ပါဆက်တင်ကိုဖွင့်ထားပါက သက်ရောက်မှုရှိမည့် IP လိပ်စာအပိုင်းအခြား။ ဖွင့်ထားပါက၊ အပိုင်းအခြားသည် စနစ်စီမံခန့်ခွဲသူနှင့်/သို့မဟုတ် စာကြည့်တိုက်မှူး၏ ပုံသေ IP လိပ်စာများအတွက် ဖြစ်လေ့ရှိသည်။ ဗလာထားခဲ့ပါက၊ လိပ်စာအားလုံးကို သက်ရောက်မှုရှိလိမ့်မည်*
