### Shortcut settings

------

Admin interface မှာ ဖော်ပြထားတဲ့ Shortcut menu item တွေကို တည်းဖြတ်ဖို့ အထောက်အကူပြုပါတယ်။

ဘယ်ဘက် pane မှာ item တစ်ခုကို highlight လုပ်ပြီး **Select** button ကို နှိပ်ပါ။ item ဟာ ညာဘက် pane မှာ ပေါ်လာပါလိမ့်မယ်။ **Save** button ကို နှိပ်လိုက်ရင် setting တွေကို save လုပ်ပြီး Admin user တွေအတွက် Shortcut menu မှာ ပေါ်လာပါလိမ့်မယ်။

item တစ်ခုကို ဖယ်ရှားဖို့အတွက် ညာဘက် pane မှာ highlight လုပ်ပြီး **Move back** button ကို နှိပ်ပြီး **Save** ကို နှိပ်ပါ။
