#### Master File: Author & Orphaned author
<hr>

This look-up table contains the authoritative list of authors used in the catalogue .

##### Author list


This enables management of the Authors master file. It displays the list of all authors in the SLiMS database , with data for:

- *Author name* (name of the author)
- *Author year* (birth year of the author)
- *Authority type* (person/organisation/conference)
- *Authority files* (source, eg. Library of Congress )
- *Last update* (when record was last edited)

This section is provided with facilities to DELETE  and EDIT author data.

To edit an author , double-click on the author , or single-click on the pencil (edit) icon.

A search function allows you to search for entries by author-name keywords.

Results can be sorted by clicking on the field name at the top of each column. 

##### Add new author

This provides the facility to add new authors directly to the data in the Senayan system. Authors' information includes the fields listed above, with the exception of *Last updated*, which is done automatically when the **Save** button is clicked.

#### **Orphaned author**:

Over time, titles may be deleted from the catalogue, and as a result entries in the master-files of Author, Subject, Publisher or Place may remain without any link to a resource held by the library. If staff wish to unclutter these master-files, the "orphaned" data entries can be identified with these tools, and deleted if considered no longer needed.

The operation is the same for each tool to manage orphaned entries in its master-file.

**To find and delete these orphaned authors**, follow these steps:

 Go to the sidebar menu and select **Orphaned Authors**. This will open the same screen as the regular Author List screen, but   **only those author records that are no longer linked to any books/resources in the library**  and are no longer used (orphaned) will be displayed. 

You can easily remove the author records from this list by selecting them and deleting them as you normally would.
