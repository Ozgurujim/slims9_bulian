#### Master File: Module & GMD
<hr>

In this module we can enter and edit master file data that is used for lookups in cataloguing data entry. 

------

**GMD** : *General Material Designation* – The physical form of the item described . While this was utilised in AACR2 cataloguing, it was superseded in RDA cataloguing by *content, media,* and *carrier* terms.

SLiMS retains this GMD functionality for libraries still using AACR2 standards. Libraries should adhere to the standard GMDs, and should not alter them except for direct translation if another language is being used.

The layout and function of this section is similar to other master-file entry/management screens.
