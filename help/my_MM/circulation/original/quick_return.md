#### အမြန်ပြန်ပို့ခြင်း



ပြန်ပို့ရန်အတွက်၊ တောင်းဆိုသူအကွက်တွင် ပစ္စည်း ID ကုဒ်ကို ရိုက်ထည့်ပြီး **ပြန်ပို့ခြင်း** ခလုတ်ကို နှိပ်ပါ။ ၎င်းကို များသောအားဖြင့် ဘားကုဒ်စကင်နာကို အသုံးပြု၍ ပြုလုပ်လေ့ရှိသည်။
