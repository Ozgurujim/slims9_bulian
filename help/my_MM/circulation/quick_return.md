#### အမြန်ပြန်အပ်ခြင်း

SLiMS စနစ်ရှိ **Quick Return (အမြန်ပြန်အပ်ခြင်း)** လုပ်ငန်းစဉ်နှင့်ပတ်သက်၍ အောက်ပါအတိုင်း အသုံးပြုနိုင်ပါသည်-

စာအုပ်များကို အမြန်ပြန်လည်အပ်နှံရန်အတွက် သတ်မှတ်ထားသော အကွက်တွင် ပြန်အပ်မည့် စာအုပ်၏ **ID ကုဒ် (Item ID code)** ကို ရိုက်ထည့်ပါ။ထို့နောက် **"ပြန်ပို့ခြင်း" (Return)** ခလုတ်ကို နှိပ်ပေးရပါမည်။ဤလုပ်ငန်းစဉ်ကို ပိုမိုမြန်ဆန်လွယ်ကူစေရန်အတွက် များသောအားဖြင့် ပစ္စည်း ID ကို လက်ဖြင့်ရိုက်ထည့်မည့်အစား **ဘားကုဒ်စကင်နာ (Barcode Scanner)** ကို အသုံးပြု၍ ဖတ်ရှုလုပ်ဆောင်လေ့ရှိပါသည်။
