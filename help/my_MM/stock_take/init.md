#### ကနဦးပြင်ဆင်ခြင်း (Initialize)

<hr>

ဤ Initialize  menuကို စာရင်းစစ်ဆေးခြင်း (stock-taking) စတင်ရန်အတွက် အသုံးပြုပါသည်။ ဤ menu တွင် အောက်ပါ ဆmenu ခွဲ များ (sub-menus) ပါဝင်ပါသည် -

- *စာရင်းစစ်ဆေးမှု အမည်*  (လုပ်ဆောင်မည့် စာရင်းစစ်ဆေးခြင်း လုပ်ငန်းစဉ်များ၏ အမည်ဖြစ်ပါသည်။ သင့်စိတ်ကြိုက်အမည်ကို သတ်မှတ်ပေးနိုင်ပါသည်။ ဤအကွက်ကို မဖြစ်မနေ ဖြည့်စွက်ရပါမည်။)
- *GMD*  (မော်ဂျူး လမ်းညွှန်ဖြစ်သော Master File -> GMD (Authority Files အောက်တွင်ရှိသည်) ကို ကြည့်ပါ)။
- *စုဆောင်းမှုအမျိုးအစား* - (မော်ဂျူး လမ်းညွှန်ဖြစ်သော Master File -> Collection Type (Lookup Files အောက်တွင်ရှိသည်) ကို ကြည့်ပါ)။
- *တည်နေရာ* - (မော်ဂျူး လမ်းညွှန်ဖြစ်သော Master File -> Location (Authority Files အောက်တွင်ရှိသည်) ကို ကြည့်ပါ)
- *စင် တည်နေရာ* - ကတ်တလောက် (Bibliography) မော်ဂျူးရှိ အချက်အလက် item (information item) ကို ရည်ညွှန်းပါသည်။
- *အမျိုးအစားခွဲခြားခြင်*း - ကတ်တလောက် (Bibliography) မော်ဂျူးရှိ အမျိုးအစားခွဲခြားမှု အကွက် (classification field) ကို ရည်ညွှန်းပါသည်။ အမျိုးအစားခွဲခြားမှု အပိုင်းအခြား (classification range) ကို သတ်မှတ်ရန် * သင်္ကေတ (wildcard)ကို အသုံးပြုပါ။ ဥပမာအားဖြင့်၊ ၁၀၀ မှ ၃၀၀ အထိ အပိုင်းအခြားရှိသော အမျိုးအစားခွဲခြားမှုများကို စာရင်းစစ်ဆေးလိုပါက 1* မှ 3* ဟု ရိုက်ထည့်ပါ။ အကယ်၍ ကျွန်ုပ်တို့ စာရင်းစစ်ဆေးမည့် အမျိုးအစားခွဲခြားမှု အပိုင်းအခြားသည် ၁၀၀ ဂဏန်းများ (100's) အတွင်းဖြစ်ပါက 1* * ဟု ရိုက်ထည့်ပါ။

ကနဦးပြင်ဆင်ခြင်း ပြီးစီးသွားပြီးနောက်၊ **လက်ရှိ စာရင်းစစ်ဆေးမှု** (Current Stocktake menu) နှင့် **စာရင်းစစ်ဆေးမှု အစီရင်ခံစာ** (Stocktake Report)  တို့သည် စာရင်းစစ်ဆေးခြင်းလုပ်ငန်းများအတွက် menu များအဖြစ် လုပ်ဆောင်ပေးမည်ဖြစ်ပြီး၊ **စာရင်းစစ်ဆေးမှု အဆုံးသတ်ရန်** (Stocktake Finish menu)၊ **လက်ရှိ ပျောက်ဆုံးနေသော item များ** (Current Lost Items)၊ **စာရင်းစစ်ဆေးမှု မှတ်တမ်း** (Stocktake Log) နှင့် **ပြန်လည်ထပ်တူပြုခြင်း** (Resynchronise) တို့နှင့်အတူ စာရင်းစစ်ဆေးမှုပြုလုပ်ရန် လမ်းညွှန် menu အဖြစ် ပူးတွဲလုပ်ဆောင်ပေးမည် ဖြစ်ပါသည်။
