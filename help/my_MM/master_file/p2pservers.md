#### Master File / Catalogue Servers

<hr>

SLiMS တွင် MARC SRU [ https://opac.perpusnas.go.id/sru.aspx] နှင့် Z39.50 SRU [ http://z3950.loc.gov:7090/voyager] အတွက် default setting ပါရှိသော်လည်း၊ default P2P သည် ၎င်းကိုယ်တိုင်ကို ညွှန်ပြနေသော်လည်း၊ အခြား catalog server များသို့ ချိတ်ဆက်မှုများ စီစဉ်ရန်အတွက်လည်း ပြဋ္ဌာန်းထားပါသည်။

**Server စာရင်း**

အသုံးပြုသူ server စာရင်းကို ပြသထားပြီး၊ အောက်ပါတို့အတွက် data များပါဝင်သည်-

- *Server name* (စာကြည့်တိုက်မှူးမှ ရွေးချယ်ထားသော အသုံးပြုရလွယ်ကူသော အမည်)

- *URI* ( server ၏ address ကို သိမ်းဆည်းထားသည် )

- *Server* ( server အမျိုးအစား- P2P, Z3950 , Z3950 SRU, MARC SRU)

- *နောက်ဆုံးအပ်ဒိတ်*

ဤအပိုင်းတွင် server data ကို DELETE နှင့် EDIT လုပ်ရန် facilities များ ပါရှိသည်။

အရာတစ်ခုကို တည်းဖြတ်ရန်၊ server အမည်ကို နှစ်ချက်နှိပ်ပါ သို့မဟုတ် ခဲတံ (တည်းဖြတ်ရန်) အိုင်ကွန်ကို တစ်ချက်နှိပ်ပါ။

ရှာဖွေရေးလုပ်ဆောင်ချက်သည် သော့ချက်စာလုံးများဖြင့် entry များကို ရှာဖွေနိုင်စေပါသည်။

ရလဒ်များကို column တစ်ခုစီ၏ထိပ်ရှိ field အမည်ကို နှိပ်ခြင်းဖြင့် စီနိုင်သည်။

##### server အသစ်ထည့်ပါ

၎င်းသည် SLiMS စနစ်သို့ cataloging server အသစ်များကို တိုက်ရိုက်ထည့်ရန် အထောက်အကူပြုသည်။

drop-down list မှ server အမျိုးအစားကို ရွေးချယ်ပြီး field တစ်ခုစီကို ဖြည့်စွက်ပါ၊ ထို့နောက် SAVE ခလုတ်ကို နှိပ်ပါ။

server တစ်ခုကို ထည့်သွင်းပြီးသည်နှင့်၊ drop-down list ရှိ item တစ်ခုအနေဖြင့် သင့်လျော်သော copy-catalogue နည်းလမ်းဖြင့် မည်သည့် server ကို အသုံးပြုရမည်ကို ရွေးချယ်နိုင်မည်ဖြစ်သည်။
