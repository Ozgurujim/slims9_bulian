ဖွင့်ထားသော Visitor Rooms များကို စာရင်းပြုစုပြီး စီမံခန့်ခွဲသည်။

##### အခန်းစာရင်း

အောက်ပါအချက်အလက်များအတွက် အခန်းများစာရင်းကို ပြသသည်-

- *အခန်းအမည်*

- *အခန်းကုဒ်*

ဤအပိုင်းတွင် Visitor Rooms များကို DELETE နှင့် EDIT လုပ်ရန် အထောက်အကူပြုပစ္စည်းများ ပါရှိသည်။

အရာတစ်ခုကို တည်းဖြတ်ရန် အခန်းပေါ်တွင် နှစ်ချက်နှိပ်ပါ သို့မဟုတ် ခဲတံ (edit) အိုင်ကွန်ပေါ်တွင် တစ်ချက်နှိပ်ပါ။

ရှာဖွေရေးလုပ်ဆောင်ချက်သည် entry များကို ရှာဖွေခွင့်ပြုသည်။

ရလဒ်များကို column တစ်ခုစီ၏ထိပ်ရှိ field name ကို နှိပ်ခြင်းဖြင့် စီနိုင်သည်။

**အခန်းအသစ်ထည့်ပါ**

၎င်းသည် SLiMS စနစ်ရှိ data သို့ visitor Rooms အသစ်များကို တိုက်ရိုက်ထည့်ရန် အထောက်အကူပြုပစ္စည်းပေးသည်။ Visitor Room အချက်အလက်တွင် အထက်ဖော်ပြပါ fields များ ပါဝင်ပြီး [အခန်းကုဒ်ကို ကျပန်းထုတ်ပေးပါမည်] *နောက်ဆုံးအပ်ဒိတ်လုပ်ခြင်း* မှလွဲ၍ **Save** ခလုတ်ကို နှိပ်လိုက်သောအခါ အလိုအလျောက်လုပ်ဆောင်သည်။

**မှတ်ချက်-** *SLiMS 9.7.2 မှစ၍ ဧည့်သည်အခန်းတွင် ရှင်းလင်းသောလုပ်ဆောင်ချက် မရှိပါ။*
