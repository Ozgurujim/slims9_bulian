#### Master File / RDA : အကြောင်းအရာအမျိုးအစား၊ မီဒီယာ၊ Carrier အမျိုးအစား

<hr>
ဤရှာဖွေမှုဇယားများတွင် ကတ်တလောက်တွင်အသုံးပြုသော authoritative RDA descriptors များပါရှိသည်။

SLiMS တွင် standard authoritative codes များနှင့် descriptor names များပါရှိသည်။ တရားဝင်စံနှုန်းများတွင် ပြောင်းလဲမှုရှိပါကသာ ဤ master files များကို တည်းဖြတ်ရန် **အထူးအကြံပြုလိုပါသည်** [ https://www.loc.gov/standards/valuelist/rdacontent.html ကိုကြည့်ပါ ]။ entry များကို မဖျက်ပါနှင့်။

------

***RDA အကြောင်းအရာအမျိုးအစား အဓိပ္ပာယ်ဖွင့်ဆိုချက်-*** သည် အရင်းအမြစ်တစ်ခုရှိ အကြောင်းအရာကို နားလည်ရန် အသုံးပြုသည့် အခြေခံဆက်သွယ်ရေးပုံစံနှင့် လူသား၏အာရုံကို သတ်မှတ်ပေးသည်။

**ဥပမာများ-** စာသား၊ မြေပုံပုံရိပ်၊ ဖျော်ဖြေသည့်တေးဂီတ၊ ပုံသေပုံရိပ်။

***RDA မီဒီယာအမျိုးအစား အဓိပ္ပာယ်ဖွင့်ဆိုချက်-*** အသံ၊ ကွန်ပျူတာ၊ ဗီဒီယို သို့မဟုတ် ကြားခံမဟုတ်သော အကြောင်းအရာများကဲ့သို့သော အကြောင်းအရာကို ကြည့်ရှုရန်၊ ဖွင့်ရန် သို့မဟုတ် လုပ်ဆောင်ရန် လိုအပ်သော အထွေထွေကိရိယာ (ကြားခံကိရိယာ) အမျိုးအစားအပေါ် အခြေခံ၍ စာကြည့်တိုက်ပစ္စည်းများကို အမျိုးအစားခွဲခြားသည်။

**ဥပမာများ-** အသံ၊ ကွန်ပျူတာ၊ ဗီဒီယို။

***RDA Carrier အမျိုးအစား အဓိပ္ပာယ်ဖွင့်ဆိုချက်-*** ၎င်းတို့သည် အရင်းအမြစ်တစ်ခု၏ ရုပ်ပိုင်းဆိုင်ရာ သိုလှောင်မှု မီဒီယာနှင့် နေအိမ်ကို ဖော်ပြသည့် အမျိုးအစားခွဲခြားထားသော ဖော်မတ်များဖြစ်ပြီး ၎င်းကို ကြည့်ရှုရန် သို့မဟုတ် ဖွင့်ရန် လိုအပ်သော အလယ်အလတ် စက်ပစ္စည်းနှင့် ပေါင်းစပ်ထားသည်။

**ဥပမာများ-** ဗီဒီယိုဒစ်ခ်၊ အသံအတိုးအကျယ်၊ အွန်လိုင်း အရင်းအမြစ် စသည်တို့။

------

သင်သည် entry တစ်ခုကို တည်းဖြတ်လိုပါက ၎င်းကို ရွေးချယ်ရမည်ဖြစ်ပြီး၊ edit pen ခလုတ်လေးကို နှိပ်ရမည်ဖြစ်ပြီး၊ ရလဒ်မျက်နှာပြင်တွင် edit ကို enable လုပ်ရန် EDIT ခလုတ်ကိုလည်း နှိပ်ရမည်။ ၎င်းသည် "ဘေးကင်းရေး ယန္တရား" အမျိုးအစားတစ်ခုဖြစ်သည်။

SLiMS သည် master file entry များကို ဘာသာပြန်ဆိုခြင်း မပြုလုပ်ပါ။ အင်္ဂလိပ်ဝေါဟာရများကို အသုံးပြုရန် မရွေးချယ်ပါက master-file ရှိ **Name** ကို သင်နှစ်သက်ရာ ဘာသာစကားဖြင့် ညီမျှသော ဝေါဟာရအဖြစ် တည်းဖြတ်သင့်သည်။ စာလုံးကုဒ်များကို မပြောင်းလဲပါနှင့်။

ဤ module ၏ interface ၏ အပြင်အဆင်နှင့် လုပ်ဆောင်ချက်သည် အခြား master-file entry/management မျက်နှာပြင်များနှင့် ဆင်တူသည်။
