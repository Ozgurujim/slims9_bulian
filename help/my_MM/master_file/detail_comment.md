#### အဓိကဖိုင်/ မှတ်ချက်စီမံခန့်ခွဲမှု 

<hr> 

စနစ်အတွင်း အကောင့်ဝင်ထားသော အသင်းဝင်များအား OPAC တွင် သီးခြားစာအုပ်ခေါင်းစဉ်များနှင့် ပတ်သက်၍ မှတ်ချက်များ (comments) နှင့်/သို့မဟုတ် သုံးသပ်ချက်များ (reviews) ရေးသားခွင့်ပြုထားရာ၊ ဤ Menu ရွေးချယ်စရာက စာကြည့်တိုက်ဝန်ထမ်းများကို အဆိုပါမှတ်ချက်များအား စီမံခန့်ခွဲနိုင်စေပါသည်။

**မှတ်ချက်စာရင်း**

၎င်းသည် အောက်ပါအချက်အလက်များနှင့်အတူ မှတ်ချက်များစာရင်းကို ပြသပေးပါသည် -

- *မှတ်ချက်* (မှတ်ချက်ပေးထားသော စာအုပ်ခေါင်းစဉ်နှင့် မှတ်ချက်၏ အကြောင်းအရာများ)
- *မှတ်ချက်ပေးသူ* (မှတ်ချက်ရေးသားခဲ့သော အသင်းဝင်၏ အမည်)
- *မှတ်ချက်ပေးသည့်ရက်စွဲ* (မှတ်ချက်ထည့်သွင်းခဲ့သည့် ရက်စွဲ)

ဤအပိုင်းတွင် မှတ်ချက်များကို ဖျက်ပစ်ရန် (**DELETE**) လုပ်ဆောင်ချက် ပါရှိပါသည်။ ဝန်ထမ်းများအနေဖြင့် မှတ်ချက်များကို တည်းဖြတ်ရန် (edit) ပြုလုပ်ခွင့် မရှိပါ။
ရှာဖွေရေးလုပ်ဆောင်ချက်သည် မှတ်တမ်းများကို ရှာဖွေနိုင်စေပါသည်။ 

ကော်လံတစ်ခုစီ၏ အပေါ်ဘက်ရှိ အကွက်အမည်ကို နှိပ်ခြင်းဖြင့် ရလဒ်များကို စီ (sort) နိုင်ပါသည်။
