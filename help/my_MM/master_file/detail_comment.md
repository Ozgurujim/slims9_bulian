#### Master File / မှတ်ချက်များ 

<hr> 

စနစ်က ဝင်ရောက်ထားသော အဖွဲ့ဝင်များအား OPAC တွင် သတ်မှတ်ထားသော ခေါင်းစဉ်များအတွက် မှတ်ချက်များနှင့်/သို့မဟုတ် သုံးသပ်ချက်များ ချန်ထားခဲ့ခွင့်ပြုသည့်နေရာတွင်၊ ဤမီနူးရွေးချယ်မှုသည် စာကြည့်တိုက်ဝန်ထမ်းများအား မှတ်ချက်များကို စီမံခန့်ခွဲနိုင်စေပါသည်။ 

**မှတ်ချက်စာရင်း** 

အောက်ပါတို့အတွက် ဒေတာပါရှိသော မှတ်ချက်များစာရင်းကို ပြသထားသည်-

- *မှတ်ချက်* (မှတ်ချက်နှင့် သက်ဆိုင်သည့် ခေါင်းစဉ်နှင့် မှတ်ချက်၏ အကြောင်းအရာ ပါဝင်သည်) 

- *မှတ်ချက်ရေးသားသူ* (မှတ်ချက်ပေးသူ အဖွဲ့ဝင်၏ အမည်ကို သိမ်းဆည်းထားသည်) -

- *မှတ်ချက်ရက်စွဲ* (မှတ်ချက်ထည့်သွင်းသည့် ရက်စွဲ) 

  ဤအပိုင်းတွင် မှတ်ချက်များကို ဖျက်ရန် အထောက်အကူပြုပစ္စည်းများ ပါရှိသည်။ ဝန်ထမ်းများအနေဖြင့် မှတ်ချက်များကို တည်းဖြတ်ရန် ပြဋ္ဌာန်းချက် မရှိပါ။ 

  အရာတစ်ခုကို တည်းဖြတ်ရန်၊ မှတ်ချက်ကို နှစ်ချက်နှိပ်ပါ သို့မဟုတ် ခဲတံ (တည်းဖြတ်ရန်) အိုင်ကွန်ကို တစ်ချက်နှိပ်ပါ။

  ရှာဖွေရေးလုပ်ဆောင်ချက်သည် မှတ်တမ်းများကို ရှာဖွေနိုင်စေပါသည်။ ရလဒ်များကို ကော်လံတစ်ခုစီ၏ အပေါ်ဆုံးရှိ ကွက်လပ်အမည်ကို နှိပ်ခြင်းဖြင့် စီနိုင်သည်။
