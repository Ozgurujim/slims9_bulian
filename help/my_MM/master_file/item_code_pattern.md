#### အဓိကဖိုင် / Item ကုဒ် ပုံစံ

<hr>

SLiMS တွင် အလိုအလျောက် စာငှား/စာပြန်လုပ်ငန်းစဉ် (automated circulation) ကို လွယ်ကူချောမွေ့စေရန် item တစ်ခုစီအတွက် ပုံမှန်အားဖြင့် Barcode (ဘားကုဒ်) ပုံစံဖြင့် item ကုဒ်များ (Item Codes) သတ်မှတ်ပေးနိုင်သော လုပ်ဆောင်ချက် ပါရှိပါသည်။ ကုဒ်၏ ဖော်မတ်(များ) ကို ဤ menu အခွဲ (sub-menu) မှတစ်ဆင့် စီမံခန့်ခွဲနိုင်ပါသည်။

**Item ကုဒ် ပုံစံစာရင်း**

၎င်းသည် အောက်ပါအချက်အလက်များနှင့်အတူ ပုံစံများစာရင်းကို ပြသပေးပါသည် -

- *Item  ကုဒ် ပုံစံ*

ဤအပိုင်းတွင် ပုံစံဒေတာများကို ပယ်ဖျက်ရန် (**DELETE**) နှင့် တည်းဖြတ်ရန် (**EDIT**) လုပ်ဆောင်ချက်များ ပါရှိပါသည်။

အချက်အလက်တစ်ခုကို တည်းဖြတ်ရန် ပုံစံအမည်ပေါ်တွင် နှစ်ချက်နှိပ်ပါ (double-click)၊ သို့မဟုတ် ခဲတံပုံ တည်းဖြတ်ရန် (edit) အိုင်ကွန်ကို တစ်ချက်နှိပ်ပါ။

ရှာဖွေရေးလုပ်ဆောင်ချက်က သော့ချက်စာလုံးများ (keywords) ဖြင့် မှတ်တမ်းများကို ရှာဖွေနိုင်စေပါသည်။

ကော်လံတစ်ခုစီ၏ အပေါ်ဘက်ရှိ အကွက်အမည်ကို နှိပ်ခြင်းဖြင့် ရလဒ်များကို စီ (sort) နိုင်ပါသည်။

**Item ကုဒ် ပုံစံအသစ် ထည့်သွင်းရန်**

 ဤလုပ်ဆောင်ချက်သည် SLiMS စနစ်ထဲသို့ ပုံစံအသစ်များကို တိုက်ရိုက်ထည့်သွင်းရန် ပံ့ပိုးပေးပါသည်။

အကွက်တစ်ခုစီကို ဖြည့်စွက်ပြီးနောက် **သိမ်းဆည်းမည်** (SAVE) ခလုတ်ကို နှိပ်ပါ။

ရှေ့ဆက်ပုဒ် (Prefix ) နှင့် နောက်ဆက်ပုဒ်  (Suffix) အကွက်များသည် ထုတ်ပေးလိုက်သော ကုဒ်တစ်ခုစီတိုင်းတွင် ပါဝင်လာမည့် ကိန်းသေများ ဖြစ်ပါသည်။ အမှတ်စဉ်နံပါတ် (Serial Number) အရှည်၏ ပုံသေတန်ဖိုး (default) မှာ ၅ ဖြစ်ပါသည်။ ၎င်းသည် ပစ္စည်းအရေအတွက် ၁ သန်းအထိရှိသော စုဆောင်းမှုတစ်ခုကို ဝန်ဆောင်မှုပေးရန် လုံလောက်မည်ဖြစ်ပါသည်။ ကြိုတင်ကြည့်ရှုခြင်း (Preview)တွင် ပထမဆုံးပေါင်းစပ်ထားသော ကုဒ်ကို ပြသပေးမည် ဖြစ်ပါသည်။

ပုံစံတစ်ခုကို ထည့်သွင်းပြီးသည်နှင့်၊ ကတ်တလောက်ပြုစုခြင်း မော်ဂျူးတွင် item များအတွက် ဘားကုဒ်များသတ်မှတ်ပေးရာ၌ item ကုဒ်များကို အစုလိုက်ထုတ်ပေးသည့်စနစ် (Item(s) code batch generator) အတွက် dropdown စာရင်းထဲရှိ ရွေးချယ်စရာတစ်ခုအနေဖြင့် ရရှိနိုင်မည် ဖြစ်ပါသည်။ 

*၄င်းသည် အမှတ်စဉ်ကို အလိုအလျောက် တိုးပေးမည်ဖြစ်ပြီး ဝန်ထမ်းများအနေဖြင့် နောက်ထပ်သတ်မှတ်ရမည့် ကုဒ်ကို မှတ်သားစောင့်ကြည့်ရသည့်အလုပ်မှ သက်သာစေမည်ဖြစ်သောကြောင့်၊ ဘားကုဒ်များသတ်မှတ်ရန်အတွက် ပုံမှန်နည်းလမ်းအဖြစ် "Item(s) code batch generator" ကို အသုံးပြုရန် အကြံပြုအပ်ပါသည်။*
