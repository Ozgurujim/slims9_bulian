#### Master File / Item Code Pattern

<hr>

SLiMS တွင် အလိုအလျောက် ဖြန့်ဝေမှုကို လွယ်ကူချောမွေ့စေရန်အတွက် ပစ္စည်းတစ်ခုစီသို့ ခွဲဝေပေးမည့် Item Code များအတွက် ပြဋ္ဌာန်းချက်ရှိပြီး၊ ယေဘုယျအားဖြင့် Barcodes ပုံစံဖြင့်ဖြစ်သည်။ ကုဒ်၏ပုံစံ(များ)ကို ဤ sub-menu မှ စီမံခန့်ခွဲနိုင်သည်။

**Pattern list**

အောက်ပါတို့အတွက် ဒေတာပါရှိသော pattern များစာရင်းကို ပြသသည်-

- *Item code pattern*

ဤအပိုင်းတွင် pattern data ကို DELETE နှင့် EDIT လုပ်ရန် အထောက်အကူပြုပစ္စည်းများ ပါရှိသည်။

ပစ္စည်းတစ်ခုကို တည်းဖြတ်ရန်၊ pattern name ကို double-click နှိပ်ပါ သို့မဟုတ် ခဲတံ (edit) icon ကို single-click နှိပ်ပါ။

ရှာဖွေရေး function သည် keyword များဖြင့် entry များကို ရှာဖွေနိုင်စေပါသည်။

ရလဒ်များကို column တစ်ခုစီ၏ထိပ်ရှိ field name ကို နှိပ်ခြင်းဖြင့် စီနိုင်သည်။

##### ပုံစံအသစ်ထည့်ပါ

၎င်းသည် SLiMS system သို့ တိုက်ရိုက် pattern အသစ်များထည့်ရန် အထောက်အကူပြုပစ္စည်းကို ပေးသည်။

အကွက်တစ်ခုစီကို ဖြည့်စွက်ပြီးနောက် SAVE ခလုတ်ကို နှိပ်ပါ။

Prefix နှင့် Suffix အကွက်များသည် ထုတ်လုပ်ထားသော code တစ်ခုစီတွင် ပေါ်လာမည့် constant များဖြစ်သည်။ Serial Number အရှည်၏ မူရင်းသတ်မှတ်ချက်မှာ ၅ ဖြစ်သည်။ ၎င်းသည် ပစ္စည်း ၁ သန်းစုစည်းမှုကို ဝန်ဆောင်မှုပေးရန် လုံလောက်ပါသည်။ preview တွင် ပထမဆုံး composite code ကို ပြသထားသည်။

ပုံစံတစ်ခုထည့်သွင်းပြီးသည်နှင့်၊ ၎င်းကို cataloging module တွင် ပစ္စည်းများသို့ ဘားကုဒ်များခွဲဝေပေးသည့်အခါ **Item(s) code batch generator** အတွက် dropdown list ရှိ item တစ်ခုအနေဖြင့် ရွေးချယ်နိုင်မည်ဖြစ်သည်။ *"Item(s) code batch generator" ကို ဘားကုဒ်များခွဲဝေရန် ပုံမှန်နည်းလမ်းအဖြစ် အကြံပြုထားပြီး၊ ၎င်းသည် serial number ကို အလိုအလျောက်တိုးမြှင့်ပေးပြီး ဝန်ထမ်းများအား ခွဲဝေပေးရမည့် နောက်ကုဒ်ကို ခြေရာခံခြင်းမှ သက်သာစေမည်ဖြစ်သောကြောင့်ဖြစ်သည်။*
