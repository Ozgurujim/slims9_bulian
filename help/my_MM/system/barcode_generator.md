#### ဘားကုဒ် ထုတ်ပေးသည့်စနစ်

------

This tool allows staff to print barcodes as they need them. Although there is an Items Barcode Printing Tool in the Cataloguing module, where barcodes would normally be printed as a batch of books are catalogued, this tool allows direct input of barcode data for printing additional barcodes as needed at any time for any purpose.

မျက်နှာပြင်ပေါ်ရှိ ကော်လံများတွင် ဘားကုဒ်များအဖြစ် ပြောင်းလဲလိုသော ကုဒ်ကို ထည့်သွင်းပါ။ ဘားကုဒ်၏ အရွယ်အစား (အသေး - Small၊ အလတ် - Medium သို့မဟုတ် အကြီး - Big) ကို သတ်မှတ်ပြီး **ဘားကုဒ်များထုတ်လုပ်ရန်** (Generate barcode) ခလုတ်ကို နှိပ်ပါ။ 

ထို့နောက် ၎င်းတို့ကို ပေါ့ပ်အပ် (popup) မျက်နှာပြင်တွင် ဘားကုဒ်ပုံစံဖြင့် ပြသပေးမည်ဖြစ်ပြီး၊ ပရင်တာဖြင့် ရိုက်နှိပ်နိုင်မည် ဖြစ်ပါသည်။

အသုံးပြုထားသော ပုံသေ အင်ကုဒ်ဒင်း (default encoding) မှာ ဘားကုဒ် 128B ဖြစ်ပါသည်။  ဤဘားကုဒ် အင်ကုဒ်ဒင်း (encoding) ကို Senayan ၏ global configuration ဖိုင်ဖြစ်သည့် `sysconfig.inc.php` တွင် ပြုပြင်ပြောင်းလဲနိုင်ပြီး၊ 

**ကွန်ပျုတာစနစ်သတ်မှတ်ခြင်း** (System Configuration) menu ခွဲတွင်လည်း သတ်မှတ်ပေးနိုင်ပါသည်။

*မှတ်ချက် ၁*
ဘားကုဒ် ထုတ်ပေးသည့်စနစ်တွင် လုပ်ဆောင်နိုင်သော စာလုံးများမှာ ASCII အက္ခရာနှင့် ဂဏန်းများ (ASCII alphanumeric character set) သာ ဖြစ်ပါသည်။

*မှတ်ချက် ၂* 

SLiMS 9.7.2 တွင် ဘားကုဒ် အင်ကုဒ်ဒင်း Code 128 နှင့် Code 39 တို့သာ အလုပ်လုပ်ပြီး System Configuration menu တွင် ရွေးချယ်နိုင်ပါသည်။
