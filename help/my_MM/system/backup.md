#### ဒေတာဘေ့စ် အရန်သိမ်းဆည်းခြင်း

------

SLiMS ဒေတာဘေ့စ်ကို အရန်သိမ်းဆည်းရန် (backup လုပ်ရန်) လုပ်ဆောင်ချက်တစ်ခု ဖြစ်ပါသည်။

မျက်နှာပြင်တွင် လက်ရှိရှိနေသော backup များ၏ အသေးစိတ်ကို အောက်ပါအချက်အလက်များနှင့်အတူ ပြသပေးပါသည် -

- **အရန်သိမ်းဆည်ခြင်းလုပ်ဆောင်သူ** (backup လုပ်ငန်းစဉ်ကို စတင်ခဲ့သော အသုံးပြုသူ)
- **အရန်သိမ်းဆည်းချိန်** (backup ဖန်တီးခဲ့သော အချိန်နှင့် ရက်စွဲ)
- **အရန်ဖိုင်တည်နေရာ** (backup ဖိုင်၏ လမ်းကြောင်းနှင့် ၎င်း၏ အမည်) နှင့် ဖိုင်အရွယ်အစား (backup ၏ အရွယ်အစား)

Backup အသစ်တစ်ခု ဖန်တီးရန် **အရန်သိမ်းဆည်းခြင်းအသစ်စတင်ရန်** (Start new backup) ခလုတ်ကို နှိပ်ပါ၊ SLiMS သည် အလိုအလျောက် backup ပြုလုပ်သွားမည် ဖြစ်ပါသည်။ SLiMS မှ ဖန်တီးသော backup ဖိုင်များ၏ ဖော်မတ်မှာ .sql ဖြစ်ပြီး TAR.GZ ကို အသုံးပြု၍ ချုံ့ထားသည် (compress)။ ၎င်းတို့ကို ဖန်တီးသည့်ရက်စွဲအလိုက်  အမည်ပေးထားပြီး `files/backup` directory ထဲတွင် သိမ်းဆည်းထားပါသည်။

Backup ဖိုင်များကို **ဒေါင်းလုဒ်ဆွဲမည်** (Download) ခလုတ်ကို နှိပ်၍ ဒေါင်းလုဒ် ရယူနိုင်ပါသည်။

Backup အရေအတွက်များပြားလာပါက စီမံခန့်ခွဲနိုင်ရန် ပုံမှန် ရှာဖွေရေး (search) နှင့် စီစဉ်ရေး (sort) လုပ်ဆောင်ချက်များကို အသုံးပြုနိုင်ပါသည်။

အကယ်၍ သင်သည် စူပါအသုံးပြုသူ "**admin**" အဖြစ် လော့ဂ်အင်ဝင်ပါက နေရာလွတ်များ တိုးလာစေရန် မလိုအပ်သော အရန်များကို ဖျက်ပစ်နိုင်ပါသည်။

------

သေချာစွာရေးဆွဲထားသော အချိန်ဇယားနှင့်အညီ backup များကို ပုံမှန်နှင့် စနစ်တကျ လုပ်ဆောင်သင့်ပါသည်။

ပြီးပြည့်စုံသော database backup (Full database backup) တစ်ခုသည် SLiMS စနစ်ကို ဆာဗာအသစ်တစ်ခုသို့ ပြောင်းရွှေ့ရာတွင်လည်းကောင်း၊ စနစ်ချို့ယွင်းမှုဖြစ်ပေါ်ပါက ပြန်လည်ရယူရန် (recovery) အတွက်လည်းကောင်း အရေးကြီးသော လုပ်ဆောင်ချက်တစ်ခု ဖြစ်ပါသည်။

**မှတ်ချက် -** *ဤ backup ကို ပြုလုပ်ရန် mysql database အသုံးပြုသူ (user) တွင် ဇယားများကို လော့ခ်ချရန် (LOCK TABLES) အခွင့်အရေး ရှိရပါမည်။*

**မှတ်ချက် -** *ဤလုပ်ဆောင်ချက်သည် SLiMS database ကိုသာ backup ပြုလုပ်ပေးပါသည်။ စာအုပ်မျက်နှာဖုံးပုံများ၊ ပူးတွဲဖိုင်များ၊ အသင်းဝင်ဓာတ်ပုံများ စသည်ဖြင့် အပ်လုဒ်လုပ်ထားသော အကြောင်းအရာများကိုမူ သီးခြား backup ပြုလုပ်ရပါမည်**။*
