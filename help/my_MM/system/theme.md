### Theme (အပြင်အဆင်) ပြင်ဆင်သတ်မှတ်ခြင်း

------

ဤပုံစံကို အသုံးပြု၍ OPAC interface နှင့် Admin module interface style နှစ်မျိုးလုံးကို ရွေးချယ်နိုင်ပါသည်။

ရရှိနိုင်သော OPAC ၏ အသွင်အပြင်များထဲမှ တစ်ခုကို ရွေးချယ်ပြီး သက်ဝင်‌စေရန် (Activate) ခလုတ်ကို နှိပ်ခြင်းဖြင့် သတ်မှတ်နိုင်ပါသည်။ theme ကို အသက်သွင်းပြီးသည်နှင့်၊ သီးခြား theme အလိုက် ကွဲပြားမည့် အသွင်အပြင် setting အမျိုးမျိုးကို ပြောင်းလဲရန် စိတ်ကြိုက်ပြုလုပ်ရန် (Customise) ခလုတ်ကို နှိပ်နိုင်ပါသည်။ စိတ်ကြိုက်ပြောင်းလဲမှုများ ပြုလုပ်ပြီးသည်နှင့်၊ *Theme configuration* pop-up မှ မထွက်ခွာမီ **သိမ်းဆည်းရန်** ခလုတ်ကို နှိပ်ရန် အရေးကြီးပါသည်။

admin module အသွင်အပြင်ကို OPAC အသွင်အပြင်ကဲ့သို့ပင် ပြင်ဆင်ထိန်းချုပ်နိုင်ပါသည်။
