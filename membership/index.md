#### အဖွဲ့ဝင်စာရင်းကိုကြည့်ရန်

ဤအရာကို စနစ်တွင် မှတ်ပုံတင်ထားသော အဖွဲ့ဝင်များကို ကြည့်ရှုရန် အသုံးပြုသည်။ ပြသထားသော အချက်အလက်များမှာ-

- အဖွဲ့ဝင် ID၊
- အဖွဲ့ဝင်အမည်၊
- အဖွဲ့ဝင်အမျိုးအစား၊
- အီးမေးလ်
- နောက်ဆုံးအပ်ဒိတ်လုပ်ထားသည်။

ဤအပိုင်းတွင် အဖွဲ့ဝင်ဒေတာများကို ဖျက်ရန်နှင့် တည်းဖြတ်ရန် အထောက်အကူပြုပစ္စည်းများ ပါရှိသည်။

#### အဖွဲ့ဝင်အသစ်ထည့်ရန်

ဤသည်မှာ Senayan စနစ်ရှိ ဒေတာသို့ အဖွဲ့ဝင်အသစ်များ ထည့်သွင်းရန် အထောက်အကူပြုပစ္စည်း ပေးပါသည်။ ပါဝင်သည့် အဖွဲ့ဝင်များ၏ အချက်အလက်များမှာ -

- *အဖွဲ့ဝင် ID* (အဖွဲ့ဝင်အတွက် ID - ဘားကုဒ်/RFID)
- *အဖွဲ့ဝင်အမည်* (အဖွဲ့ဝင်၏ အမည်အပြည့်အစုံ)
- *မွေးသက္ကရာဇ်*
- *မှတ်ပုံတင်သည့်ရက်စွဲ* (မှတ်ပုံတင်သည့်ရက်စွဲ)
- *သက်တမ်းကုန်ဆုံးရက်* 
- *အဖွဲ့အစည်း* (အဖွဲ့အစည်းအမည်၊ အေဂျင်စီ သို့မဟုတ် အဖွဲ့အစည်းအမည်)
- *အဖွဲ့ဝင်အမျိုးအစား* 
- *ကျား/မ* 
- *လိပ်စာ* (အိမ် သို့မဟုတ် အလုပ်လိပ်စာ)
- *စာတိုက်ကုဒ်* (ဇစ်ကုဒ်)
- *မေးလ်လိပ်စာ* (စာပို့စာများအတွက်)
- *ဖုန်းနံပါတ်* 
- *ဖက်စ်နံပါတ်* 
- *ကိုယ်ရေးကိုယ်တာ ID နံပါတ်* (မှတ်ပုံတင်ကတ်နံပါတ်ကဲ့သို့သော ကိုယ်ရေးကိုယ်တာ ID နံပါတ်)
- *မှတ်စုများ* (အဖွဲ့ဝင်နှင့်ပတ်သက်သော အတိုချုံးမှတ်စုများ)
- *ဓာတ်ပုံတင်ပါ* (အဖွဲ့ဝင်၏ ဓာတ်ပုံဖိုင်) သို့မဟုတ် [ဖွင့်ထားပါက] ကင်မရာလုပ်ဆောင်ချက်ကို အသုံးပြုပါ။
- *အီးမေးလ်* (အီးမေးလ်လိပ်စာ)
- *စကားဝှက်* (နှင့် အတည်ပြုချက်)

သက်တမ်းကုန်ဆုံးရက်တွင် **အလိုအလျောက်သတ်မှတ်ခြင်း** အတွက် အမှန်ခြစ်ကွက်တစ်ခု ပါရှိသည်။ ဤလုပ်ဆောင်ချက်၏ ရည်ရွယ်ချက်မှာ အလိုအလျောက်သတ်မှတ်ခြင်းကို အမှန်ခြစ်ထားပါက အဖွဲ့ဝင်၏ သက်တမ်းကုန်ဆုံးရက်ကို အဖွဲ့ဝင်အမျိုးအစားပေါ် မူတည်၍ တွက်ချက်မည်ဖြစ်သည်။ သို့သော် အမှန်ခြစ်မထားပါက သက်တမ်းကုန်ဆုံးရက်ကို ရွေးချယ်ခြင်းဖြင့် ကိုယ်တိုင်ဆုံးဖြတ်နိုင်သည်။

ဤပုံစံတွင် **ဆိုင်းငံ့ထားသော အသင်းဝင်ခြင်း** ရွေးချယ်ခွင့်ကိုလည်း ပေးထားသည်။ ဆိုင်းငံ့ထားသော အသင်းဝင်ခြင်းကို အမှန်ခြစ်ထားပါက ထိုအဖွဲ့ဝင်သည် ၎င်းတို့၏ အသင်းဝင်အဖြစ် အသက်ဝင်နေဆဲဖြစ်ပြီး ဒေတာဘေ့စ်တွင် သိမ်းဆည်းထားဆဲဖြစ်သော်လည်း ငှားရမ်းနိုင်မည်မဟုတ်ပါ။ စာကြည့်တိုက်စည်းမျဉ်းများကို ချိုးဖောက်သော အဖွဲ့ဝင်များအပေါ် ပြစ်ဒဏ်အဖြစ် အသုံးပြုနိုင်ပါသည်။
